# Поиск клиентов по OpenStreetMap

Локальное приложение для поиска отмеченных в OpenStreetMap магазинов и компаний. Интерфейс открывается в браузере автоматически; API-ключ и регистрация не нужны.

## Запуск

На Linux дважды щёлкните `Поиск клиентов Я карты.desktop`. Если KDE спросит, разрешите запуск. Альтернативно запустите `app.py` установленным Python 3.

Приложение слушает только `127.0.0.1` и открывает случайный локальный порт. Чтобы остановить сервер, нажмите «Закрыть приложение» в окне.

## Поиск

Выберите категорию и город из выпадающего списка, укажите радиус 2, 5 или 10 км и нажмите «Найти». В списке популярные российские города; через «Другой город…» можно ввести любой населённый пункт вручную. Например, вариант «Цветы — магазины цветов» ищет объекты OSM с тегом `shop=florist`. Доступен поиск магазинов, продуктов, одежды, обуви, электроники, косметики, мебели, игрушек, товаров для животных, пекарен, аптек, кафе, ресторанов, салонов красоты, оптики и подарков. Режим «По названию» ищет совпадение с введённым названием.

Поиск выполняется вокруг найденного центра города, а не по всей его административной границе.

Приложение получает организации из OpenStreetMap, а затем дополняет связанные по тегу `wikidata=Q…` карточки публичными сведениями Wikidata: описанием, официальным названием, сайтом, телефонами, email, соцсетями, датой основания, изображениями и ссылками на Wikipedia, если они есть. В результатах видны контакты и статус Telegram-бота. Нажмите «Все данные», чтобы посмотреть поля из обоих источников, координаты и все теги объекта OSM. CSV включает контакты, сведения Wikidata и полный набор исходных тегов.

Используются открытые структурированные источники OSM и Wikidata, а не автоматический обход всего интернета. Внешние сайты организаций не скрейпятся: у них разные форматы, ограничения и условия использования. Wikidata дополняет только организации, явно связанные с записью OSM; если такой связи нет, сторонних сведений может не быть.

В строке статуса поиска показывается, сколько карточек было дополнено Wikidata. Если источник временно недоступен, результаты OSM всё равно отображаются. За один запрос обогащается не более 50 связанных Wikidata-записей.

## Telegram

«Публичный Telegram-бот не найден» означает, что в тегах найденного объекта OpenStreetMap не указана ссылка на Telegram-аккаунт с именем, заканчивающимся на `bot`. Это не доказывает отсутствие бота: он может быть не указан на карте, иметь закрытый доступ или быть связан с компанией неочевидным образом. Ссылка на Telegram-канал сама по себе не считается подтверждением бота.

## Ограничения бесплатных данных

OpenStreetMap и Wikidata заполняют добровольные участники; у многих магазинов нет записи, адреса, телефона или связанной записи Wikidata. Приложение возвращает найденные объекты выбранной категории в радиусе, максимум 500 записей, а не весь интернет или полный коммерческий справочник. Публичные Nominatim, Overpass и Wikidata могут отвечать медленно, временно ограничивать запросы или быть недоступны. Используйте поиск вручную и умеренно; в приложении есть пауза между запросами геокодирования и кэш центров городов и записей Wikidata.

Данные карты предоставлены участниками OpenStreetMap и доступны по лицензии ODbL; структурированные данные Wikidata доступны по CC0. См. [условия Nominatim](https://operations.osmfoundation.org/policies/nominatim/), [Overpass API](https://wiki.openstreetmap.org/wiki/Overpass_API) и [Wikidata Query Service](https://www.wikidata.org/wiki/Wikidata:SPARQL_query_service).
